# Kalkulathor 🧮

> **My first calculator project from 2019** — built when I was just starting out in university and learning web development.

A simple calculator built with vanilla HTML, CSS, and JavaScript. No frameworks, no build tools — just one file and pure enthusiasm.

## Live Demo

**[Try it here →](https://kalkulathor.netlify.app/)**

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Memory functions: **MC**, **MS**, **MR**, **M+**
- Quick operations: square root, square, reciprocal, negate
- Colorful gradient background because 2019 me loved gradients

## Tech Stack

- HTML
- CSS
- JavaScript (inline, no modules, no ES6 — just vibes)

## Running Locally

Just open `index.html` in your browser. That's it.

## Note

This project is a relic from when I was first learning to code. The code is intentionally left untouched as a reminder of where I started. We all begin somewhere.
